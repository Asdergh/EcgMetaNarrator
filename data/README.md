# ECG data loaders

Этот пакет предоставляет загрузчики только с дескрипторами для выбранных архивов ЭКГ. 
Перед использованием реестров импортируйте `data`, чтобы встроенные наборы данных были зарегистрированы.:

```python
from data import get_loader, label_to_vector

records = get_loader("ptbxl", root="/datasets/ptb-xl", limit=10)
for record in records:
    # file_path has no signal-file extension
    print(record["file_path"], record["label"], record["meta"])
```

У каждого полученного элемента есть точные ключи `file_path`, `label` и `meta`.
Загрузчики проверяют только имена файлов, заголовки и целевые метаданные; они никогда не загружают
образцы сигналов. `SignalReader` - это единственная зависящая от формата точка входа для
последующего чтения записи.

Выбранные наборы данных и их целевые источники задокументированы в
["наборы данных.csv`](./datasets.csv). Набор данных включается только в том случае, если его источник
содержит поддерживаемый категориальный или двоичный целевой объект и необработанную запись ЭКГ.

Для `SignalReader.read` требуется `wfdb` для полных пар `.dat/.hea` и `scipy` для записей
`.mat`. `SignalReader.metadata` возвращает `n_sig` и `fs` из `.hea`; для `.mat` без
заголовка эти поля имеют значение `None`. Неполная пара `.dat/.hea` считается отсутствующей
записью. Эти необязательные зависимости намеренно не импортируются загрузчиками
дескрипторов.

Для Challenge 2018 целевая метка берётся из бокового WFDB-файла `.apn`: наличие символа
`A` и большинство символов `A` среди `A/N` означает `APNEA`; при равенстве или большинстве
`N` используется `NO_APNEA`. Сначала применяется `wfdb.rdann`, а текстовый разбор используется
только когда `wfdb` недоступен. Чтение `.apn` не загружает значения ЭКГ.

Для Challenge 2020 при нескольких диагнозах применяется фиксированный приоритет из
`mappings.py`; патологические классы имеют приоритет над `NORM`, поэтому результат не зависит
от порядка элементов в заголовке или порядка обхода множества.
